# Example records

Each folder is one example. The records are selected from real work unless a row says they are synthetic, and each provenance file says what was kept and what was removed.

| Folder | What it holds | Command from the repository root |
|---|---|---|
| [checkout-review/](checkout-review/) | Three synthetic recordings for the README walkthrough: a failing rounding assertion, a correction and a successful retry | |
| [validation-history/](validation-history/) | A recording with failed tests, a correction and a retry, with its provenance and `retrieval-costs.json`, which holds recorded measurements and not performance guarantees | `python tools/inspect_recorded_run.py` |
| [launch-review/](launch-review/) | A coordinator and two Codex subagents | `python tools/inspect_agent_tree.py` |
| [cross-provider/](cross-provider/) | Claude reading Codex findings through MCP | `python tools/inspect_cross_provider.py` |
| [native-command/](native-command/) | A search followed by retrieval of one command's output. `native-command-response.json` is generated by `record_native_contract.py`, and `--check` verifies it without changing it | `python tools/record_native_contract.py --check` |
| [reviewer-visibility/](reviewer-visibility/) | What models answered when given copies of a conversation with parts left out, with and without lines stating what was left out | `python tools/build_visibility_example.py --check` |
| [synthetic-codex/](synthetic-codex/) | `codex.jsonl`, a synthetic transcript fixture, and the compact view, detailed view and parsed output generated from it | `python tools/regenerate_examples.py --check` |
| [structured-clip/](structured-clip/) | A preserved desktop export. Its [provenance](../docs/records/structured-clip-provenance.json) describes the selection | `python tools/regenerate_examples.py --check` |
| [controlled-run/](controlled-run/), [codex-retrieval/](codex-retrieval/) | Earlier recordings and derived views, described in the [controlled run](../docs/studies/controlled-run.md) and [retrieval recording](../docs/studies/codex-retrieval.md) write-ups | |

Use the Python environment installed by [the setup guide](../README.md#try-it). The commands read these records without executing the commands recorded inside them.

`tools/regenerate_examples.py` owns the legacy generated views and indexes.
Run it with `--check` to detect drift. Synthetic Claude parser fixtures live in
`tests/fixtures/`; they are test inputs, not recordings of a Claude session.
