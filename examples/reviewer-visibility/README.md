# Reviewer visibility example

One saved Claude Code conversation, five copies of it, and what reviewing models said about each copy. [The write-up](../../docs/reviewer-visibility.md) explains it.

| File | Contents |
|---|---|
| [coding-session.jsonl](coding-session.jsonl) | The recording, with private records removed |
| [copies/](copies) | The five texts the reviewers were given |
| [return-note.txt](return-note.txt) | The note to paste beside a review in the coding conversation |
| [inventory.json](inventory.json) | The counts the notes are written from |
| [reviewer-prompt.txt](reviewer-prompt.txt) | The prompt each reviewer was given, with the copy pasted in |
| [reviews/](reviews) | Each review, as the reviewer wrote it |
| [reviews-first-note/](reviews-first-note) | Ten earlier reviews, made before the note's counts were corrected |
| [results.json](results.json) | Each answer beside the answer the copy supports |
| [return/](return) | What was pasted into four coding conversations, each reply, and the commands run afterwards |
| [provenance.json](provenance.json) | What was removed from the recording, and what is not regenerated |
